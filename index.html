Panduan Cepat

▾
  1. Download jadwal dari portal kampus kamu (SIA, Labkom, SISKA, dll) — biasanya format Excel (.xlsx) atau CSV.
  2. Import file Teori lewat zona drop di atas. Kolom terdeteksi otomatis (matkul, kode, sks, hari, jam, kelas, ruang, dosen).
  3. Import file Praktikum (opsional) jika jadwal lab ada di file terpisah.
  4. Cek bentrok — konflik jadwal (jam tumpang tindih di hari sama) ditandai merah otomatis.
  5. Tambah manual untuk kelas yang belum ada di Excel, atau edit dengan klik baris jadwal.
  6. Ekspor ke ICS (Google/Apple Calendar), PNG (gambar), PDF (cetak), atau CSV.
  7. Tersimpan otomatis di browser kamu — tutup tab, datanya tetap. Tanpa daftar, gratis.
